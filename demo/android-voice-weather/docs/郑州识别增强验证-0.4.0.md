# 郑州识别增强验证（0.4.0）

日期：2026-10-22；设备：小米 23049RAD8C，Android 15。

## 实现

- 通用 Vosk 识别输出最多 5 个候选；原始第一候选保留在日志和界面中。
- 只在完整天气询问的城市槽精确匹配“正中/郑重”时，优先选择同句上下文、同日期的“郑州”识别候选；没有合适候选则提出“可能是郑州”的受限解释。
- 已正确识别的城市不重排；普通聊天不改写；不对全部城市做拼音或近音替换。
- 纠错询问明确说出“我听到的城市可能是郑州”，肯定确认前不查询，否定时不查询。
- 未重训声学模型，也没有用受限天气语法替代通用转写。该实现改善的是天气城市候选解释，不代表原始文字识别准确率已经提高。
