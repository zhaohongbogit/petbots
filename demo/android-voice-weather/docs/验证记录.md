# Android Demo 验证记录

日期：2026-10-22（Asia/Shanghai）。此记录用于验证本地语音识别和有限主动交互的可行性，不代表树莓派 3B 已通过验证。

## 初版 0.1.0 实现与产物

- 独立 Android 工程：`demo/android-voice-weather`，未改动两个旧 MQTT Demo 或 i.MX7D 实现。
- Android 原生 Java，Vosk Android 0.3.75，中文模型 `vosk-model-small-cn-0.22`。
- 模型随 APK 打包；三段固定合成音频也随 APK 打包，安装后可离线自检。
- APK：`app/build/outputs/apk/debug/app-debug.apk`，约 130 MiB，包含多种 CPU 架构的原生库和模型，使用开发调试签名。
- 天气数据采用 Open-Meteo；运行中只有打开真实天气模式且明确确认后才发起实际天气请求。

单元测试覆盖普通聊天、无确认时的“是的”、确认窗口、完整肯定/否定句、含糊回答、超时、冷却及重置。单元测试只覆盖纯状态机，不代表音频硬件或网络已验证。

## 合成音频性能观察

- 1.75 秒天气样本：三次识别为 1615、1473、1547 ms，RTF 约 0.92、0.84、0.89。
- 0.57 秒肯定样本：654、669 ms，RTF 约 1.15、1.17。
- 0.60 秒否定样本：1267 ms，RTF 约 2.10。
- 每次文件自检重新创建识别器，因此包含识别器初始化开销；不适合据此推算持续流式识别吞吐量。
- 一次 `dumpsys meminfo` 观察到应用总 PSS 240270 KB（约 235 MiB），RSS 376140 KB（约 367 MiB）。这是包含模型、界面和运行时的单次快照，不是峰值，也不能套用于树莓派。
