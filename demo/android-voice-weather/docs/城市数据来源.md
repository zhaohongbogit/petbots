# 离线城市表

当前随 APK 提供 `app/src/main/assets/cities.tsv`，包含 314 个中国大陆城市。每行保存城市中文名、纬度、经度和 GeoNames ID；App 不进行在线地名搜索，不上传识别全文。天气确认后仅发送所选城市坐标。

## 来源与处理

- 城市名称范围来自 [Administrative-divisions-of-China 的 pc.json](https://github.com/modood/Administrative-divisions-of-China/blob/master/dist/pc.json)，提取以“市”结尾的市级名称及四个直辖市。
- 城市坐标来自 [GeoNames 中国数据集](https://download.geonames.org/export/dump/CN.zip)，按中文名称或去掉“市”后缀的别名精确匹配居民点。同名记录优先采用人口较大的居民点，人口相同时优先行政中心。这里使用的是城市参考点，非用户设备定位。
- GeoNames 数据为 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)，数据归属 [GeoNames](https://www.geonames.org/)，已进行筛选和格式转换。名称数据源采用 WTFPL，原许可见同目录 `city-names-LICENSE.txt`。
- 本次名称列表中的 318 个城市有 314 个匹配成功；仙桃、潜江、可克达拉、昆玉未获得可靠的中文别名精确匹配，因此未纳入。不是完整行政区划或全球地名库；自治州、区县、海外城市及其他未入表地点不作支持承诺。

## 复现

`tools/prepare_cities.py` 固定校验本次源文件 SHA-256。上游数据变化时脚本会拒绝生成，需要人工评审后再更新固定校验值；普通构建直接使用已提交的 TSV，不会重新下载城市数据。

```bash
python3 tools/prepare_cities.py --city-list /path/to/pc.json --geonames /path/to/CN.zip
```

省略路径时从以上公开来源下载。城市中文名精确匹配，不自动修复同音字；例如语音把“苏州”识别成“宿州”时，需要根据确认询问拒绝并重试。
