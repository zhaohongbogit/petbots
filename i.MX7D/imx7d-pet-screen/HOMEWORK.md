# 作业截图与完成时间规划

手机打开“和小七聊聊”→“发送作业截图 / 规划时间”。

1. 使用系统文件选择器选择一张作业截图；应用不申请全相册权限。
2. 预览后点击“识别作业”，手机将图片转换为最长边1600像素、不超过1MiB的JPEG，通过认证局域网接口发送至iMX7；iMX7使用既有模型代理识别图片。
3. 识别结果是草稿。可逐项修改作业文字与预估分钟数、删除或补充任务。看不清的内容标记待确认；耗时是估计，不是识别出的事实。
4. 确认开始时间和可用时长，点击“已核对作业与耗时，生成计划”。默认开始时间为打开页面时的手机时间，可用时长默认90分钟，均在页面上可修改。
5. iMX7按已确认的列表顺序排程，累计专注25分钟后休息5分钟（任务结束后不额外加休息）；较长任务拆成时间段。显示预计结束时间、休息和总时长；超时明确提示，不擅自删减任务。

## 接口

- POST /homework：JSON包含id、image（纯JPEG Base64）、可选text。
- POST /homework/plan：JSON包含id、tasks（title/minutes）、start_minutes、available_minutes。
- GET /status?id=...：复用现有状态查询，新增homework字段返回识别草稿。
- 两个POST仍需手机来源IP和X-Pet-Key。图片请求最大1500000字节，计划请求最大16000字节；最多20项作业，单项预估1–180分钟，可用时间15–720分钟。
- 原始图片不写入iMX7持久存储或聊天历史。识别文本和确认计划进入原有最近12组问答；手机选择的图片在页面内存中。代理/上游日志留存由服务配置决定。
- 主屏仍显示宠物面孔。手机显示识别结果和时间计划；iMX7文字调试面板可查看记录。

## 验证与限制

- 现有模型代理已用自建中文作业图片实测，准确返回数学练习册第12页第1–5题、语文第3课朗读两遍。
- 11项排程断言、9项格式校验断言通过；两端构建与签名校验、覆盖安装通过。手机向iMX7发未认证请求收到403。
- 图片内容仅用作资料，识别提示词要求忽略图片中的指令；草稿必须经用户核对确认。
- 当前一次处理一张截图，需要两端页面在前台；不支持跨重启恢复正在识别的任务。密集长截图可能需要裁剪后再上传。
- 不包含语音播报、倒计时、提醒、完成打卡、家长日报或作业答案检查；复杂模糊图片的识别不能保证准确。
- 真机完整链路已验证：系统文件选择器选取测试截图 → 手机上传 → iMX7 调用代理识别两项任务 → 手机核对确认 → iMX7排程 → 两端显示计划。
- 修改耗时重算已验证，长任务正确分段休息并提示超过90分钟预算；修改内容后旧计划清空并提示重新生成，修改后再次确认通过。
- 最终截图：`build/homework-verification/phone-plan-final.png`、`board-plan-final.png`。设备已回到面孔页面，手机保留测试计划。
