# i.MX7D 宠物屏幕测试

原生 Java / Canvas 陪伴宠物原型，包名 `com.zhb.petscreen`，运行于 i.MX7D 的 Android Things 8.1。
默认页面只显示铺满屏幕的卡通面孔，支持平静、喜、怒、哀、乐、愁、惊、思考和说话嘴型。自动实时监听语音，转换的文字显示在表情最下面；不显示文字输入、调试按钮或配置开关。原来的设备测试通过额头长按入口保留。

面孔额头区域保留隐藏设备入口：持续按住 3 秒打开“设备设置”，可返回 Android Things 系统桌面、进入设备测试或关闭设置。短按仍只触发宠物微笑，按住后移动或提前松手会取消打开设置。

新增录音 5 秒及本地播放按钮。录音保存为应用私有目录 `last-recording.wav`，使用 AudioRecord 直接采集 16kHz/16-bit/单声道 PCM，并按实际样本数写入 WAV；每次录音替换上一段，不上传。显示样本峰值和实际时长；播放显示媒体文件时长和音量。离开页面停止录放音。

对话回复默认使用设备已安装的中文离线TTS播报；播报期间嘴巴会张合。本地规则表情、模型回复和作业计划都会进入同一播报出口。

历史云端语音入口会录制最多 7 秒的 16 kHz WAV，再请求 OpenAI 兼容的 `/audio/transcriptions`；当前板端入口已切换为本地独立唤醒与 VAD + Paraformer 整句识别，不走此路径。语音代理通过 `speech_base`、`speech_model`、`speech_key` 单独配置；未配置时只提示，不录音或上传。当前自建模型代理只开放聊天与模型列表端点，实测音频端点返回 404，因此当前安装包的云端语音识别保持未配置状态。

## 构建

运行 `bash build.sh`。使用本机 Android SDK build-tools 35.0.0、android-29 平台及 JDK。
APK 位于 `build/pet-screen.apk`；本地测试签名材料在忽略的 build 目录中，不应提交或分享。

## 已验证

2026-09-08：APK 构建与签名验证通过，安装并启动于连接的 i.MX7D。
实际设备截图检查四种表情，无明显裁切；ADB 模拟点击可切换，模拟滑动可显示轨迹，坐标与次数更新。

## 手动验收

1. 手指依次点击四个按钮，确认选中状态与表情对应。
2. 在脸部画横线、竖线和圆，检查轨迹连续、跟手。
3. 点击靠近屏幕四角的位置，观察坐标是否接近对应边界，有无死区。
4. 检查实际屏幕的颜色、亮度、文字清晰度。

尚未验证：实体触摸精度、多点触控、插耳机后的真实人声音量与音质、云端语音识别及长时间稳定性。

2026-09-09 录放音修复验证：真机采集 80,000 个样本，对应 5,000 ms，WAV 为 160,044 字节；Android 播放器读取时长也是 5,000 ms。此前约 960 ms 的异常由 AAC/MediaRecorder 路径改为按实际样本写 WAV 后消除。当前未检测到耳机接入，所以还不能确认实体听感。

2026-09-09 本地语音播报验证：Google 中文 TTS 初始化成功；真实模型回复和本地“表现得很生气”指令均收到 speaking、completed 回调，后者同时显示 angry/0.95 并在播报期间切换张嘴画面。由于没有耳机，只能确认合成和播放任务执行完成。

2026-09-09 设备语音编排验证：用局域网假 ASR 上游和新增代理路由完成一次全链路测试。i.MX7D 录制 7,000 ms，上传 224,351 字节 multipart；转写文字进入真实 Qwen 对话，执行 happy/0.9 并启动本地 TTS。该测试证明设备录音、上传、响应解析、对话、表情和播报的编排可用，不代表硅基流动 ASR 已连通。测试语音配置随后已清除。


新增标题点击开关轻量动画，目标约 15 fps；增加 PetPerf CPU 计时和 PetAudio 录放音日志。性能初测和音频阻塞见 PERFORMANCE.md；云端准备见 CLOUD-INTEGRATION.md。


局域网手机音箱：新增 PhoneOutputActivity，可从底部“手机音箱”进入。构建部署、使用和验证结果见 ../imx7d-phone-speaker/README.md。


历史版本曾使用“小七陪伴宠物”文字对话页；当前为表情与语音界面。个人代理配置、手机中文输入与真实模型验证见 TEXT-CHAT.md；原设备测试功能保留在“设备测试”入口。

## 阿洛助手（i.MX7D）

阿洛已直接接入表情主界面，自动监听并在底部显示原始转写。语音播报、唤醒、真实天气默认开启；天气仍需口头确认后才查询。没有文字输入和配置选项。构建、使用方法和验证边界见 [ALUO.md](ALUO.md)。
