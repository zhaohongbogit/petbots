# 表情主界面自动语音（2026-10-29）

按本轮要求，i.MX7D 主界面只保留原有表情与底部两行转写，移除板端文字输入、语音/唤醒/天气配置选项和调试入口按钮。前台自动监听，播报、唤醒及真实天气默认启用；天气仍须口头确认。旧阿洛Activity转入表情主页面。

## 修改

- `ChatActivity.java`：将语音控制器接入原有表情与嘴型，底部显示Vosk原始临时/最终转写。没有附着到界面的EditText、Switch或Button；维护用额头长按入口保留。配对手机功能保留，板子不显示文字草稿。
- `VoiceController.java`：从原阿洛页面抽出语音流程，自动唤醒/命令/确认/联网天气/离线TTS；前后台与迟到回调隔离。
- `BoardSpeech.java`：持久自由听写解码器、一次预热、实时转写。自然句末对该句PCM进行受限词表复核以获得独立唤醒证据，不在每帧并行运行两个解码器。句末复核有额外算力成本，不宣称无限负载实时。
- `BoardVoiceOutput.java`：默认中文离线TTS、播放完成/错误/25秒保护和取消。播报期间停止采音，结束后隔离500ms恢复，避免回声误确认。
- `AluoActivity.java` 与 manifest：旧入口跳转，主页面禁止自动键盘。
- 构建脚本、设备测试与使用说明同步；手机阿洛和board诊断模块不修改，保留工作区其他未提交代码。
