# i.MX7D 皇包车旅行应用（测试环境）

在现有 `com.zhb.petscreen` 中集成旅行服务，应用名为“阿洛旅行助手·测试”。继续使用表情、底部转写、本地唤醒/ASR和H340离线播报；没有键盘或配置开关。不是把Spring服务放在ARMv7上运行：板端通过POST JSON访问Mac上的现有hbc-agent `/api/chat` 和 `/api/approvals/{id}`，业务、身份隔离、报价、审批、幂等仍由服务端 `OrderGateway` 负责。没有改动hbc-agent仓库或手机端。

## 使用

1. 说“你好阿洛”，听到“收到”后说“我想预订东京三天包车”或“进入旅行服务”。
2. 本地测试包可包含用户明确指定的固定测试账号及验证码。先完整回读固定号码；说“确认发送验证码”才调用短信接口，随后自动提交内置测试验证码。没有这个私有构建资产时，改为语音输入手机号、确认短信、语音输入验证码。短信和登录都是测试环境；错误不会自动重复提交。
3. 服务每轮播报结束后直接监听下一句，不必每轮唤醒。基础信息每次只问一个字段；简短数字只填入刚刚问到的字段，儿童、老人、无行李不默认补零。旅行对话中无输入20秒会重新打开命令监听，继续原会话；无需再次唤醒。只在明确退出或音频失败等情况回到唤醒。按服务提示补充日期、时间、人数、分尺寸行李和路线，确认行程、选择车型与支付方式。
4. 返回车型卡片后，应用逐个播报接口中的车型、容量、整数分价格和不可选原因。说“下一个车型”“上一个车型”“重听车型”浏览；“选这个车型”只提交当前可选且未过期的报价选项，获取最终报价，不创建订单。
5. 订单写操作返回待审批后，完整播报近期服务回复、报价编号、支付方式及创建测试订单的影响。只有说“确认创建测试订单”才批准该次审批。“是的”不能批准；“重听待办”重新播报；“拒绝本次操作”拒绝。确认窗口从播报完成且麦克风实际就绪开始，最长20秒。
6. 本版只批准单一 `create_order` 操作。付款、取消、退款、其他操作或混合批次不在板端批准，可明确拒绝后通过原客户端继续。不会把发起支付称为付款完成。
7. 说“退出旅行服务”回到普通助手；“新建旅行对话”或“退出旅行登录”清除本机当前会话/登录。若请求超时，先在原客户端核对短信/最新订单；不会自动重试。

初始需求会由后端登录流程保留，登录后仍可补充。客户令牌只在内存中保持，应用重启需重新登录。应用进入后台会停止采音、取消当前HTTP连接及本地确认授权；服务器已接受的请求可能继续完成，不能据断网判断订单未创建。此时也不自动重试。

## 本地服务与部署

当前Mac测试地址以设备私有 `files/hbc-agent.json` 为准，配置不通过公开Activity Intent传入。服务仅复用现有Spring JAR和本机 `.env`；关闭飞书、短链和运营网页。需要Mac保持运行且与板子网络互通，不是完全离线下单。

```sh
# 前台启动；也可设置 HBC_JAVA_HOME、HBC_ENV_FILE、PORT、HOST
bash i.MX7D/imx7d-pet-screen/start-hbc-service.sh /path/to/hbc-agent

# 生成可选的固定测试登录资产，交互输入不回显；不要将凭据写在命令行
python3 i.MX7D/imx7d-pet-screen/configure_test_login.py http://MAC_LAN_IP:8788
bash i.MX7D/imx7d-pet-screen/build.sh --reuse-model
bash i.MX7D/imx7d-pet-screen/tests/device/build.sh

# 安装应用后，通过同签名维护instrumentation写入私有服务地址并重启应用
bash i.MX7D/imx7d-pet-screen/configure-hbc-service.sh http://MAC_LAN_IP:8788
```

固定登录资产只在被忽略的 `build/hbc-private-login.json` 中生成，构建时打入 `assets/hbc-test-login.json`。按用户本次明确要求，它是可从APK提取的固定测试登录参数，因此这次APK仅用于本地测试，不能当发布包分发。绑定生成时的精确Agent地址；改接其他地址时不会自动使用该参数。源码、文档、测试报告和日志均不包含实际验证码。私有参数不随服务地址配置自动生成或改变。

构建未提供私有资产时仍能使用普通语音登录。完整APK包含模型；更新APK复用设备上的模型。使用原签名更新，不清除数据/录音，不修改音量。服务地址支持HTTPS，明文仅允许回环或RFC1918测试机IP；不跟随HTTP重定向，不在URL传令牌。板端不含HBC业务API Key。

## 验证

- `HbcTravelTest`：真机运行的单元/集成测试，HTTP仅回环模拟服务，音频输入/播报被替换；验证登录、短信/审批口令、时间窗口、身份、异常不重试和控制器。不是实际短信或下单验证。
- `HbcProvisionTest`：只写服务地址，不存客户令牌，不调用业务。
- `HbcConnectivityTest`：真实板端→Mac探活与未登录聊天，仅创建登录challenge，不提交手机号、验证码或审批。
- 实际真人唤醒、播报、短信、登录、报价和订单落库分别记录在[本轮报告](reports/2026-10-30-hbc/README.md)，不能用模拟测试/构建代替。

语音始终在板端识别；进入旅行服务后的文字发送给hbc-agent。生产ASR日志仅记录模式、字数和耗时，不记录全文；登录阶段屏幕显示“登录信息已识别”，不显示验证码。服务回复不进入原宠物对话持久化历史；长回复按80字符分段播报，任何分段失败/超时均不启用待审批操作的确认窗口。

## 报价衔接修复

板端发送 `interactionMode: voice`，仅影响该对话；原网页/KMP默认流程保持兼容。Spring新增VoiceTripIntake逐字段收集。模型只说报价进度时，运行时要求它实际执行只读报价或追问一项；再次只有进度则明确返回尚未取得报价。板端处理vehicleQuote并显示请求处理中状态。只读聊天失败后可以人工重新报价，短信和审批结果不确定时仍禁止重试。

启动脚本优先使用本机已验证的 `build/hbc-service/spring-agent.jar`，也可用 `HBC_SERVICE_JAR` 指定版本；没有该包时才使用hbc-agent的target产物。服务重启会丢失其内存登录、行程和审批，需在切换前确认。验证见 [修复报告](reports/2026-10-30-hbc-quote-fix/README.md)。

## 语音日期

voice模式使用VoiceDateInput规范化中文数字、空格及日期写法；只提供月日时单独补问年份，不默认今年。请求完成后恢复显示实际转写，方便核对识别内容。2027年1月1日的本轮回归与真人验证边界见[日期修复报告](reports/2026-10-30-hbc-date-fix/README.md)。
