# i.MX7D 本地性能初测

日期：2026-09-08。实际设备：i.MX7D PICO，Android Things 1.0.15 / Android 8.1，512 MB 级内存。

## 结果

| 场景 | 应用 CPU 平均，单核 100% | 应用 PSS 快照 | 有效 CPU 样本 |
| --- | ---: | ---: | ---: |
| 静态待机 | 0.98% | 22.23 MiB | 13 |
| 轻量动画 | 10.45% | 24.48 MiB | 47 |
| 动画＋录音 | 12.91% | 25.62 MiB | 3 |
| 动画＋回放 | 11.77% | 26.63 MiB | 1 |

CPU 使用 Process.getElapsedCpuTime 的增量除以 elapsedRealtime 增量，按时间加权；阶段切换的首个区间不参与统计。每秒日志采样有少量开销。CPU 是应用进程，不含 audioserver、编码服务、SurfaceFlinger 等进程，不能作为整机占用。双核机器单核 100% 对应总算力约一半。

PSS 来自各阶段一次 dumpsys meminfo 快照，不是峰值。首轮在应用内每秒读取 PSS 引入明显干扰，已移除；build/perf 为弃用首轮，build/perf-final 为本次数据，summary.json 为汇总。最终进程 PID 为 3210。

动画为脸部轻微上下浮动和缩放，调度目标约 15 fps；未测实际显示帧率，不代表复杂动画性能。录音、回放样本很少，特别是回放，仅供初步定位。未做整机负载、长时间稳定性或泄漏验证。

## 本地音频文件与播放器时长已修复

- 旧 AAC 路径曾出现墙钟约 5 秒、媒体时长仅 813–1344 ms 的异常。
- 2026-09-09 改用 AudioRecord 采集 16 kHz、16-bit、单声道 PCM，并根据实际样本数写 WAV。
- i.MX7D 真机采集 80,000 个样本，文件 160,044 字节，样本时长和播放器读取时长均为 5,000 ms。
- 当前系统没有检测到耳机接入；真实人声完整度、音量和音质仍需插耳机实听，不能把播放器时长相等视为听感验收。

## 对话与本地 TTS 快照

2026-09-09 在同一台 i.MX7D 上，以真实模型回复和本地中文 TTS 播报采样。静态待机 PSS 为 20,422 KiB、进程 CPU 瞬时 0%；模型回复后的 TTS 与嘴型阶段 PSS 为 25,094 KiB，连续四次 `top` 瞬时 CPU 为 6.4%、9.6%、16.6%、16.6%。该设备为双核，`top` 总量显示 200%；这些是瞬时快照，不能当作平均值或峰值。

Google TTS 对约 80 字回复依次报告 ready、speaking、completed，播报任务约 19.8 秒。没有耳机，未验证实际声音。
