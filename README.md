# ZHB-iot

目录按设备和用途归类：

- `i.MX7D/`：i.MX7D Android Things 陪伴宠物及手机扬声器调试项目。
- `RaspberryPi/RaspberryPi3B-smart-car/`：Raspberry Pi 3B 智能小车的新项目代码。
- `demo/`：独立实验及旧版参考项目，包含阿洛 Android 本地语音项目（`demo/android-voice-weather/`）、`doraemon` 及两个 MQTT 小车旧项目。
- `docs/`：硬件研究和验证资料。
- `output/`：已生成的概念素材和输出物。

各项目保留原有独立 Git 历史；进入具体项目目录后再执行其构建或 Git 命令。
