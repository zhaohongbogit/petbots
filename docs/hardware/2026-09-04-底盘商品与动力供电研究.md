# 底盘商品与动力供电研究

研究日期：2026-09-04。范围：已有硬件复用、低成本动力供电；不采购、不接线、不运行硬件控制。

## 1. 结论

1. 用户确认实车是四轮车架、后驱马达、前舵机转向。新版应采用后驱动力控制与前轮转向模型，不设计左右差速或原地旋转。
2. 用户确认标准款、不带霍尔测速；随后提供的商品规格图标明标准款为GA25-370，工作电压6–12V，额定电流0.65A、堵转电流1.2A。优先采用此对应版本的商品资料，而非之前官网候选页的电机参数；仍不是实测或厂家完整数据表。
3. 原6V镍氢包不再作为优先采购方向：L298N压降后电机电压余量偏小。可优先评估带保护的2S（标称7.4V、满电8.4V）成品动力电池包，但不能保证整个放电过程均有足够动力；不要直接使用满电12.6V的3S包。
4. 撤回以官网候选页4A/6A堵转电流判断用户马达必然超过L298N能力的推断。当前标注1.2A，可保留L298N做短时低速验证；电流测试电压、启动峰值和模块散热仍待确认，不能据此保证持续可靠。
5. 资料没有证明视频卡顿原因；RTSP部署、编码及Docker配置仍需单独提供。

## 4. 对动力不足的解释

### 电气因素：优先测量，不直接定因

原4节AAA标称约6V。电池带载压降、开关和导线接触压降，再叠加L298桥路压降，都会降低电机可用电压。

ST数据表给出的单通道直流电流上限为2A；1A条件桥路总压降最大3.2V。该额定条件也依赖散热，不能当成廉价模块的无条件持续能力。

S3中4A/6A堵转电流不再用于用户标准款评估，U3对应值为1.2A。此值低于芯片单通道2A直流上限，但仍需核对测试工况和散热；额定上限不是推荐长期工作点。不得把双桥总电流相加后当成单个马达可用能力，不自行并联两路输出。

更强的电池不会强行向电机灌入固定电流，但会减少原先由弱电池造成的限流，使启动/卡滞时更容易达到较大电流。因此不能只升级电池、不核对驱动和保护。

### 软件因素：已在上一轮隔离模拟确认

旧车端默认避障；距离小于0.5m时drive控制量被限制为0.3。它可能造成低速，但不是实际电气故障的证明。现场应同时记录请求控制量、最终PWM、距离、带载电压和轮子表现。

## 5. 采购建议的修订

- 不再优先选择6V镍氢包：经过L298N后电机电压余量偏小。
- 低成本优先评估2S锂离子成品动力包（标称7.4V、满电8.4V），约2000–3000mAh；要求明确持续放电能力，初选不低于3A，并与实际启动负载、线材、保险及模块能力复核。此规格是工程候选，不是已核价商品或实车验证结果。
- 配套2S锂离子专用8.4V充电器与保护/均衡方案；不使用裸电芯自行拼装，不把普通8.4V适配器当充电器，不把BMS当作充电器。电池只供电机动力，舵机与Pi独立供电。
- 2S满电位于页面工作范围内，但经L298N压降后，尤其电池后段，电机端可能低于6V。不能保证全程动力足够；应以带载验证决定是否接受该简化方案，不靠加大PWM或升压强行补救卡滞。
- 3S锂离子满电12.6V超过页面12V上限，不直接采用，也不能把L298N压降当稳压保护。若需要稳定9V，需另行评估稳压和保护，非当前最低成本首选。
- 树莓派仍可独立充电宝供电；舵机使用符合实际型号要求的独立稳压支路。不得让高压动力电池直接接舵机或Pi。
- L298N模块的逻辑供电、板载稳压跳帽、使能跳帽需要实物确认；芯片数据表不能代替模块接线图。
- 若电机确实要求较大启动电流，可能需要少量预算更换驱动，而不是通过更高电压硬顶。此时先报价再决定，不扩大到更换底盘和主板。

## 6. 对低成本新设计的影响

- 保留Pi3B、后驱马达、前舵机、摄像头、云台与传感器。
- 驾驶采用归一化动力档位和转向标定；没有编码器就不声称闭环车速或精确距离。
- 舵机中位、左右机械极限必须现场标定，不直接套20–160度。
- 该结构有最小转弯半径，不能原地旋转；AI只开放短时低速运动，不能承诺精确旋转角度。
- 优先减轻非必要配重，勿把多个充电宝都堆到车上；布置需考虑前轮转向负载。
- 本地超时停车只能覆盖软件正常调度条件；没有独立硬件保护时，不用于无人看护或楼梯环境。
